## 1. 何のために・結論

- **何のために**: 話題を探しに行かなくても、開けば「自分が答える物・やる事・起きた事」が流れていて、押せば横で読んで答えられる画面にする。
- **配置**: 案 A「3 列 + 席 1 つ」。列は あなたの番／タスク・リマインド／通知 の 3 本で固定。項目を押すと右の「席」にスレッドが 1 枚開く。
- **話題の一覧**は列にしない。入口は 流れの項目・右腕・「探す」の板（Ctrl+K）の 3 つ。
- **右腕**は席に座る会話の 1 つ。広い幅（1340px 以上）では席の既定の住人。スマホは下のバーの 4 つ目。
- **スマホ**は 3 列を横に送る（scroll-snap）。下のバーの 3 つの列の名前でも切り替えられる（スワイプだけにしない）。
- **最初のコードの段 D1**: 640px 以上の画面の左が流れの 3 列になる（タブレット・PC）。スマホは D2。
- **段**: D0〜D10 の 11 本（小 2・中 7・大 2 ≒ 12 日。推測）。サーバーを触るのは D7・D8・D9。
- **今ある計画**: K7 はこの形から起こし直して D10。K9 は 7 画面 → 4 画面。#416 と lead の L7 は取り込む。
- **性格 A「夜勤の計器盤」は残す**。構造の手本だけ「メッセンジャー」→「計器盤の列」に書き直す。

## 3. 配置の案

| | 案 A: 3 列 + 席 1 つ | 案 B: 1 本の流れ + 席 2 つ | 案 C: 自分で並べる Deck |
|---|---|---|---|
| 形 | 列は 3 本で固定。右に席 1 つ（話題か右腕） | 3 種を時刻順の 1 本にし、上で絞り込む。右に話題と右腕の 2 席 | 3 列が既定。話題・右腕・場所の流れも列として足す・外す・並べ替える |
| 探さずに使えるか | ◎ 開けば 3 つが並ぶ。未読の話題は通知の列に出る | ○ 1 か所で済むが、あなたの番が時刻に埋もれる | △ 並べ方を自分で保つ仕事が増える |
| スマホでの成り立ち | ○ 3 列を横に送る。下のバーに位置が出る | ◎ 縦 1 本。横の送りが要らない | ✗ 列が増えると送りが長い |
| 今の部品をどれだけ使えるか | ◎ 会話・入力欄・カード・見出し・一覧（探すの板）・板 | ○ 同じ。流れの行だけ新しい | △ 列の入れ物・並びの保存・列のメニューが新しい |
| オーナーの答えとの合い方 | ◎ | △ 「列に出す物 3 つ」「Deck」から離れる | △ 「会話は列にしない」「UI を意識しない」に当たる |
| 実装コスト | 約 12 日 | 約 10 日 + 流れの口（サーバー。#449 の先取り） | 約 17 日以上（推測） |
| 運用コスト | 0 円。60 秒ごとの読み込みが 3〜4 本増える | 0 円。流れの口 1 本 | 0 円。開いた会話の数だけ 5 秒ごとの読み込み |
| 弱い所 | PC でも会話は 1 枚。820 幅で席を開くと列は 1 本 | タスク（期日順）と通知（新しい順）は並びが違い、混ぜにくい | 前の見本と同じ。重さを測っていない |

**推し: 案 A。** 答えに一番素直で、今の部品をほぼそのまま席に入れられる。B は #449（流れを 1 本に）のときにもう一度比べる。C の「留める」「2 枚目」は A の後に足せる（§6.3）。

| 論点 | 答え |
|---|---|
| 列の並び | 左から あなたの番 → タスク・リマインド → 通知。並べ替え・足す・外すは作らない |

### 4.2 列の 1 項目

```
[印] 種類の語 ・ 場所                 時刻か残り時間
題（1〜2 行。太さ 600）
要約 1 行（--text-secondary）
[主の操作] [副の操作]                 ← 在る種類だけ
```

- 高さは 44px 以上。項目の間は 4px の余白で、線は引かない。
- 種類の語: 許可・質問・判断待ち・確認／今日・期日の日付／返事・PR・Issue・知らせ。印は今の `Mark`（点）を使う。色だけにしない。
- 押すと: 話題に結びつく項目は席で開く。タスクは項目の頭の丸のボタンで完了（［取り消す］の知らせ）。GitHub は［対応］と外へのリンク。知らせは文とリンクだけ。
- 列の見出し: 名前 + 数（あなたの番 = 件数、通知 = 新着。タスクは数だけで色なし）。空のときは `Empty` の 1 文。

### 4.3 スレッド

- 見出しは今の `TopBar`（戻り先・題・場所・モデル・閉じる）。入力欄・カード・道具の動きの 1 行は今の部品のまま。
- 行は吹き出しをやめる。エージェント: 名前の 1 行（`--font-xs`）+ 文（地なし・左寄せ・最大 `--c-talk-max`）。自分の発言: `--muted` の面（左寄せ・角丸 10・幅は文なり）。左右に振り分けない。
- 主役は文。アイコン・色の付いた名前・顔は足さない。

### 4.4 動き

| 何が | どれだけ | reduced-motion |
|---|---|---|
| 席が開く・閉じる | 右から 16px の `translateX` + `opacity`。200ms（スマホの全面は 300ms） | 動かさず切り替える |
| 項目が流れに入る | 上から 4px + `opacity`。200ms。同時に 3 件を超えたら動かさない | 動かさない |
| 答えた項目が退く | `opacity` 120ms の後に消す。下の項目は詰めるだけ（高さは動かさない） | すぐ消す |
| スマホの列の送り | 指に付いて動く（scroll-snap）。下のバーを押したときは 200ms の送り | 押したときはすぐ切り替える。指の送りはそのまま |
| 新着の印 | 項目の左の線が 2 秒で差し色から引く（`opacity`） | 引かずに残す |

守る事は今のまま: 300ms を超えない（例外は新着の印の 2 秒。`opacity` だけ・1 回）・動かすのは `transform` と `opacity` だけ・バウンスなし・読み込み時の演出なし。

| 段 | 色 | 使う所 |
|---|---|---|
| 0 台 | `--bench`（D3 で新。`--bg` より暗い実色。流れの列の形だけ） | 列と列・列と席の間の溝（8px）、余り |
