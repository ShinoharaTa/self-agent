# self-agent 要求（再始動版）

> 2026-10-01 の再始動で決めた要求と方針の正本。Rust 版時代の要件定義は `docs/archive/REQUIREMENTS-rust.md` と `docs/archive/REQUIREMENTS_V2-rust.md`（参照のみ）。
> 実装の現状は `CLAUDE.md`、フェーズごとの実装仕様は `docs/plan/`。

## 目的

ADHD のエンジニア（オーナー 1 人）のタスク管理と情報整理を助ける、Discord 専用サーバーに常駐するエージェント。
主な入口はスマートフォンの Discord アプリ。作業ごとに場（チャンネル）を分け、文脈が混ざらないようにする。

## 要求

| ID | 要求 | 優先 | 状態（2026-10-03） |
|---|---|---|---|
| R1 | Claude の公式 SDK（Claude Agent SDK）でエージェントループを組む | 必須 | 済（P1） |
| R2 | Pi（pi-mono）のように軽い: 少ないツール、短く静的なシステムプロンプト、小さい常駐メモリ | 必須 | モデル側は済。常駐メモリ・起動時間は実機で未計測 |
| R3 | セッションごとにチャンネルを指定カテゴリ内に自動で作る | 必須 | 済（P2） |
| R4 | 専用サーバーの #inbox とセッションのチャンネルから、いつでも話しかけられる | 必須 | 済（P1・P2）。DM と他サーバーは対象外 |
| R5 | 会話からタスクを抽出・登録・一覧できる | 必須 | 登録・一覧・完了・題名と期限の変更・やめる（dropped）は済。削除は作らず dropped で代える。時刻・優先度は P4 |
| R6 | リマインダー（時刻・放置タスクの声かけ） | 次点 | P4 |

| R9 | ヘッドレス機で常駐。sudo 不要で `systemctl --user` 管理 | 必須 | 停止処理は済。unit と自動再起動は P3 |
| R10 | ナレッジ: Web のページや調べた内容・会話のまとめを、題名・要約・要点・タグで保存し、どのセッションからでも検索できる（ページ本文は保存しない。URL の無いメモも可。削除はボタンで確認） | 次点 | 設計済み・実装中（#35） |

将来に回すもの: マルチ LLM プロバイダー、Slack、Web UI、スキルマーケット。

## 決定事項

| 項目 | 決定 | 理由 |
|---|---|---|
| 実行基盤 | TypeScript + Claude Agent SDK。`query()` を `resume` で呼ぶ | 自分用プロジェクトなら Claude Max の利用枠で動かせる唯一の経路 |
| 認証 | `claude setup-token` の長期トークン。Bot 専用の `CLAUDE_CONFIG_DIR` | 普段使う `~/.claude` と設定・履歴を分ける |
| モデル | Opus 1 つに固定。effort は env で指定 | キャッシュはモデル・effort ごとに別 |
| サブエージェント | 使わない。話題を分けたいときはセッション（チャンネル）を分ける | Pi の方針（中身の見えない処理を入れ子にしない） |
| セッション | 1 セッション = 1 テキストチャンネル。状態は置き場のカテゴリ（進行中 / 待ち / 完了）で表す | フォーラム投稿は流れて見えなくなる |
| 公開範囲 | Bot は非公開。動くのは env `SELF_AGENT_ALLOWED_GUILD_IDS` のサーバーだけ。DM には反応しない | 利用枠と記憶をオーナー以外に使わせない |
| 権限 | Bot にサーバー全体の Manage Channels と Pin Messages。カテゴリは非公開にしない | 専用サーバーなので他に触られて困るチャンネルがない |
| ツール | 全セッション共通の固定集合。追加は全セッションで一度にまとめる | ツール集合が変わると全セッションでキャッシュが外れる |
| プロンプトキャッシュ | システムプロンプトは静的。日時は各発言先頭のヘッダ。履歴は追記のみ | 規則は `CLAUDE.md` |
| 通知 | 鳴らすのは朝のサマリー・リマインド・承認待ち・停止の 4 種だけ（P4） | 多すぎると無視され、少なすぎると忘れる |
| 不可逆操作 | チャンネル削除はボタンで確認してから。要約は DB に残す | 戻せない操作を自動で行わない |
